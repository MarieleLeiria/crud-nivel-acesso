## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

Projeto criado para implementação de uma arquitetura limpa, testando as possibilidades do nest para construção de uma API, anterior ao desenvolvimento do front end(BFF)

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
